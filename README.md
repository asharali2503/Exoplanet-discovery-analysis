# Exoplanet Discoveries by Method (1989–2026)

A bar chart race that tracks how exoplanets have been found since the first confirmed discovery in 1989 — radial velocity, transit photometry, direct imaging, microlensing, and the rest, ranked year by year by how many planets each method had turned up so far.

**[View the visualization →](https://public.flourish.studio/visualisation/29824552/)**

## About

Different detection methods have taken turns leading the pack over the decades. Radial velocity dominated the early years; transit photometry pulled ahead once space telescopes like Kepler came online. This chart replays that shift frame by frame instead of just describing it.

## Data

Discovery counts come from NASA's [Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/), grouped by detection method and discovery year, covering confirmed planets from 1989 through 2026.
